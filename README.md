# inciq-news

Еженедельные черновики новостей сайта [инсик.рф](https://инсик.рф) для Telegram-бота и архив опубликованных выпусков. Бот отдельный от derm-atlas-news, его токен лежит в секрете TELEGRAM_BOT_TOKEN. Код бота перенесён из derm-atlas-news без карточек сайта и без GitHub Pages.

## Как это работает

1. Сессия Claude в проекте «Инсик.рф» кладёт черновик в drafts/ГГГГ-ММ-ДД-inciq/digest.html (Telegram HTML, сообщения разделяются строкой `<!--split-->`) и отправляет его в main.
2. Workflow send-draft присылает владельцу канала черновик в личку с кнопками «Опубликовать», «На правки», «Отклонить» и ждёт нажатия до часа. Дальше нажатия раз в 10 минут проверяет workflow approve.
3. «Опубликовать»: пост уходит в канал «Записки дерматолога», digest.html копируется в archive/ГГГГ-ММ-ДД-inciq.html, папка черновика удаляется. Страницу выпуска на сайте выкладывает Claude после этого.
4. «На правки»: черновик остаётся, метка .sent снимается, новая версия придёт с теми же кнопками. «Отклонить»: черновик удаляется.
5. Файл TEST в папке черновика включает тестовый режим: публикация уходит только владельцу.

## Требования

- Бот добавлен администратором канала с правом публикации сообщений: по списку администраторов он находит владельца, которому шлёт черновики.
- Владелец канала один раз написал боту /start, иначе бот не может прислать сообщение в личку.

## Проверка черновика локально
